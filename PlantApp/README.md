
# 🌱 planto

## About the App

planto is an iOS app that helps users organize their plant care routines. Users can create watering reminders, manage plant information, and track their watering progress.




## Main Features

- **Add Plants:** Create plant reminders with details such as name, room, lighting conditions, watering frequency, and water amount.
- **Track Watering Progress:** View watering progress and mark plants as watered.
- **Edit Reminders:** Update existing plant information and watering preferences.
- **Delete Plants:** Remove plants from the list.
- **Completion Screen:** Display a celebration message when all plants have been watered.


## Technologies Used

- **Swift:** Programming language used to develop the app.
- **SwiftUI:** Framework used to build the user interface.
- **Xcode:** Development environment used to build and test the app.
